# Say how sure

## When it applies

You report a claim: that a change works, why a bug happens, what a number means.

## The rule

Mark each claim as measured (you ran it), inferred (it follows from what you read), or guessed (it is plausible but unchecked). Use no word stronger than the evidence: "works" needs a run, and a claim with no evidence file is `not confirmed`.

## What it changes

- Write "this fixes the crash" after reading the code → write "inferred from the code; not run".
- State a cause as fact → say "guessed: the cache, because the error started after the cache change".

## Not this

Hedging every sentence. Mark the strength once per claim and keep the sentence plain.
